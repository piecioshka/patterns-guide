# Instrukcje projektu

## Pamięć projektu

@MEMORY.md

Trwałe fakty o tym repo dopisuj do `MEMORY.md`; preferencje ogólne, fakty o użytkowniku
i referencje niezwiązane z repo — do globalnej pamięci współdzielonej.

- Jeden fakt = jeden punkt listy, format `- [RRRR-MM-DD] [kategoria] treść`.
- Kategorie: `projekt`, `preferencja`, `referencja`.
- Sprawdź, czy fakt już nie istnieje — aktualizuj zamiast duplikować. Nieaktualne usuwaj.
- Lista posortowana malejąco po dacie. Pisz zwięźle, po polsku.
